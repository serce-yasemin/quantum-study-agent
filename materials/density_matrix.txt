Density matrices: a short primer for one qubit

1. From a state vector to a matrix
A pure qubit state is a column vector |ψ⟩ = a|0⟩ + b|1⟩ with |a|² + |b|² = 1.
Its density matrix is the outer product ρ = |ψ⟩⟨ψ|, a 2×2 matrix:

    ρ = | |a|²   a·b* |
        | a*·b   |b|² |

For example, |+⟩ = (|0⟩ + |1⟩)/√2 gives ρ = [[0.5, 0.5], [0.5, 0.5]].

2. Reading the diagonal
The diagonal entries ρ₀₀ = |a|² and ρ₁₁ = |b|² are the probabilities of measuring
0 and 1 in the computational basis. They are real, non-negative and add up to 1,
so the trace of every density matrix is Tr(ρ) = 1.

3. Reading the off-diagonal
The off-diagonal entries ρ₀₁ and ρ₁₀ are called coherences. They are complex
conjugates of each other. Their size |ρ₀₁| tells how much of a genuine
superposition the state is; their angle carries the relative phase between |0⟩
and |1⟩. If we write |ψ⟩ = a|0⟩ + b·e^(iφ)|1⟩ with real a, b ≥ 0, then
ρ₀₁ = a·b·e^(−iφ), so the relative phase is φ = −arg(ρ₀₁) = arg(ρ₁₀).

4. Mixed states
Sometimes we do not know which pure state was prepared: with probability p it
was |ψ₁⟩, with probability 1 − p it was |ψ₂⟩. The density matrix is the weighted
average of the two pure density matrices:

    ρ = p·|ψ₁⟩⟨ψ₁| + (1 − p)·|ψ₂⟩⟨ψ₂|

Example: 0.6 of |0⟩ and 0.4 of |+⟩ gives
ρ = 0.6·[[1, 0], [0, 0]] + 0.4·[[0.5, 0.5], [0.5, 0.5]] = [[0.8, 0.2], [0.2, 0.2]].
Mixing always shrinks the coherences compared with a pure superposition.

5. Pure or mixed? The purity test
The purity is Tr(ρ²). It equals 1 for a pure state and is smaller than 1 for a
mixed state. For one qubit its smallest value is 0.5, reached by the maximally
mixed state ρ = I/2 = [[0.5, 0], [0, 0.5]], which has no coherence at all.

6. Picture: the Bloch sphere
Every one-qubit density matrix can be written ρ = ½(I + x·σx + y·σy + z·σz),
where (x, y, z) is the Bloch vector. Pure states sit on the surface of the unit
sphere (length 1); mixed states sit inside it (length < 1); the maximally mixed
state is the centre. The purity is Tr(ρ²) = ½(1 + x² + y² + z²).
