Density matrices of pure states: a short primer for one qubit

1. From a state vector to a matrix
A pure qubit state is a column vector |ψ⟩ = a|0⟩ + b|1⟩ with |a|² + |b|² = 1.
Its density matrix is the outer product ρ = |ψ⟩⟨ψ|, a 2×2 matrix:

    ρ = | |a|²   a·b* |
        | a*·b   |b|² |

For example, |+⟩ = (|0⟩ + |1⟩)/√2 gives ρ = [[0.5, 0.5], [0.5, 0.5]].

2. Reading the diagonal
The diagonal entries ρ₀₀ = |a|² and ρ₁₁ = |b|² are the probabilities of measuring
0 and 1 in the computational basis. They are real, non-negative and add up to 1,
so the trace of every density matrix is Tr(ρ) = 1.

3. Reading the off-diagonal
The off-diagonal entries ρ₀₁ and ρ₁₀ are called coherences. They are complex
conjugates of each other. Their size |ρ₀₁| tells how much of a genuine
superposition the state is; their angle carries the relative phase between |0⟩
and |1⟩. If we write |ψ⟩ = a|0⟩ + b·e^(iφ)|1⟩ with real a, b ≥ 0, then
ρ₀₁ = a·b·e^(−iφ), so the relative phase is φ = −arg(ρ₀₁) = arg(ρ₁₀).
Example: |+i⟩ = (|0⟩ + i|1⟩)/√2 has φ = 90° and ρ = [[0.5, −0.5i], [0.5i, 0.5]].

4. The global phase disappears
If |ψ⟩ is multiplied by a global phase e^(iγ), the bra is multiplied by
e^(−iγ), and the two cancel in |ψ⟩⟨ψ|. So the density matrix does not change:
two vectors that differ only by a global phase give exactly the same ρ. This
is one reason density matrices are a cleaner description than vectors.

5. Properties of a pure-state density matrix
- Hermitian: ρ₁₀ = ρ₀₁*.
- Tr(ρ) = 1 and the diagonal entries are between 0 and 1.
- ρ² = ρ, because ρ is a projector: |ψ⟩⟨ψ|ψ⟩⟨ψ| = |ψ⟩⟨ψ|. Hence Tr(ρ²) = 1.
- For a pure state, |ρ₀₁|² = ρ₀₀·ρ₁₁: the coherence is as large as it can be.

6. Picture: the Bloch sphere
Every one-qubit density matrix can be written ρ = ½(I + x·σx + y·σy + z·σz),
where (x, y, z) is the Bloch vector. Reading it off the matrix:
x = 2·Re(ρ₀₁), y = −2·Im(ρ₀₁), z = ρ₀₀ − ρ₁₁.
For a pure state x² + y² + z² = 1, so it sits on the surface of the sphere.
Example: |+i⟩ has ρ₀₁ = −0.5i, so (x, y, z) = (0, 1, 0).
